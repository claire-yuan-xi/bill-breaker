# Bill Breaker frontend

TanStack Start + React 19 + Tailwind v4, deployed to Cloudflare Workers.

```sh
npm install
npm run dev   # http://localhost:3000
```

The hero photo lives at `public/images/capitol.jpg` (public domain; see `public/images/CREDITS.md`).
Without Supabase keys the app runs frontend-only: live AP news and saved bills (stored in the browser) still work.
